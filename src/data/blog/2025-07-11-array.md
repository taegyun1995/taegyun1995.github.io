배열은 가장 기본적인 자료구조 중 하나로, **동일한 타입의 데이터 여러 개를 연속된 메모리 공간에 저장하는 구조**입니다. 각 데이터는 인덱스라는 위치 정보를 가지며, 이 인덱스를 사용해 원하는 요소에 직접 접근할 수 있습니다.

## 배열의 특징

- **고정된 크기**: 대부분의 프로그래밍 언어에서 배열은 생성한 뒤 크기를 변경할 수 없습니다.
- **인덱스 기반 접근**: 인덱스를 사용하면 특정 위치의 데이터에 `O(1)`로 접근할 수 있습니다.
- **연속된 메모리 공간**: 데이터가 메모리에서 연속적으로 위치해 지역성과 캐시 효율을 기대할 수 있습니다.

## 주요 연산의 비용

| 연산 | 시간 복잡도 | 이유 |
| --- | --- | --- |
| 접근 | `O(1)` | 시작 주소와 인덱스로 위치를 계산합니다. |
| 검색 | `O(n)` | 정렬되지 않았다면 요소를 순서대로 확인합니다. |
| 중간 삽입 | `O(n)` | 뒤에 있는 요소를 한 칸씩 이동합니다. |
| 중간 삭제 | `O(n)` | 빈 공간을 메우기 위해 요소를 이동합니다. |

## Java에서 배열 사용하기

```java
int[] numbers = {10, 20, 30, 40, 50};

// 인덱스를 이용한 접근: O(1)
int third = numbers[2];
System.out.println(third); // 30

// 모든 요소를 순회하는 검색: O(n)
int target = 40;
for (int index = 0; index < numbers.length; index++) {
    if (numbers[index] == target) {
        System.out.println("찾은 위치: " + index);
        break;
    }
}
```

Java 배열은 생성할 때 길이가 결정됩니다. 중간에 값을 삽입하려면 더 큰 배열을 만들고 기존 요소를 복사하거나, 내부적으로 동적 배열을 사용하는 `ArrayList` 같은 컬렉션을 선택해야 합니다.

## 배열을 선택할 때 확인할 점

배열은 데이터의 개수가 비교적 고정되어 있고 인덱스를 통한 접근이 많을 때 단순하고 효율적입니다. 반대로 중간 삽입과 삭제가 빈번하거나 크기를 예측하기 어렵다면 동적 배열이나 연결 구조가 요구사항에 더 적합한지 비교해야 합니다.
